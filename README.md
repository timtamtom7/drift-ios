# Drift

Sleep tracking with deep analysis and a weekly report.

## What it does

- Sleep scoring
- deep sleep analysis
- smart wake
- weekly reports

## Targets

- iOS with Mac and watch companions

## Structure

Key types:

- ``DeepSleepAnalysis``
- ``AIInsightService``
- ``WeeklyReportService``
- ``SmartWakeService``
- ``SleepScheduleService``
- ``FamilyService``
- ``HealthExportService``

Reads Apple Health and has a `SleepCommunityView`.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.
